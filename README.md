# GTKScheduling

GTKScheduling is GTK 3 based app to simulate CPU scheduling.

## Install
See [INSTALL](./INSTALL.md)

## Run the app
Launch the app from the application menu or run:
```sh
gtkscheduling
```

## Configure scheduling parameters
The scheduling parameters can be changed by editing the file data/tasks.
